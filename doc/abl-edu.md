 
你现在要基于我提供的设计参考图，为我的个人网站新增一个 ABL 教育专题页。

## 背景

我的个人网站中要合并一个 AI Builder Lab / ABL 教育品牌页面。
这个页面不是普通课程介绍页，而是一个高端 AI 教育 Landing Page，用来表达：

> AI Builder Lab 不只是教孩子使用 AI 工具，而是建立孩子的“能力三角”。

核心概念：

```text
ABL 能力三角 = AI 思维 × 审美力 × 判断力
```

请参考我提供的图片做视觉方向，但不要机械切图，也不要完全照抄图片。图片只是风格和结构参考。请做成真实可维护的网页代码。

---

## 目标

新增一个单页响应式网页：

```text
/ai-builder-lab
```

如果项目使用 Next.js App Router，则创建：

```text
app/ai-builder-lab/page.tsx
```

如果项目使用 Pages Router，则创建：

```text
pages/ai-builder-lab.tsx
```

请先检查项目结构后再决定，不要盲目创建。

---

## 页面形态

采用：

```text
PC 端：大网页连续滚动 Landing Page
移动端：H5 长页滚动
```

不要做 fullpage.js 那种强制上下滑动分屏。
不要做一屏一屏卡死的滚动。
不要用整张图片当网页。
所有文字都必须是真实 HTML 文本，方便 SEO 和后期修改。

## 视觉风格

整体方向：

```text
高级
大气
留白充足
浅色未来感
教育科技品牌
克制而有未来感
```

不要做成厚重黑色赛博朋克风。
不要做少儿编程机构的卡通风。
不要做普通培训机构红黄蓝风。

推荐色彩：

```text
页面背景：#F6F8FF / #EEF4FF / white
主文字：#0B1220
次级文字：#475569
主蓝：#2563EB
科技青：#06B6D4
高级紫：#7C3AED
深色模块：#0B1020
```

视觉元素：

* 大留白
* 柔和渐变
* 圆角卡片
* 轻微玻璃感
* 简洁线性图标
* 能力三角 SVG 图形
* 少量轻动画
* 不要视觉噪音

动画建议：

* section 进入视口淡入
* 三角图形轻微浮动
* CTA hover 效果
* 卡片 hover 轻微上移

如果项目中已经有 Framer Motion，可以使用；如果没有，不要强行安装，使用 CSS transition 即可。

## 技术要求

1. 先检查现有项目：

   * package.json
   * Next.js 版本
   * 是否使用 App Router
   * 是否使用 Tailwind CSS
   * 是否已有全局样式和布局组件

2. 不要破坏现有个人网站。

3. 页面必须响应式：

   * PC 宽屏布局
   * 平板适配
   * 手机 H5 长页

4. SEO：

   * 设置 title
   * 设置 description
   * 如果项目支持 metadata，请添加 metadata

建议：

```text
title: AI Builder Lab｜面向未来的 AI 原生教育
description: AI Builder Lab 提出能力三角模型，培养孩子的 AI 思维、审美力和判断力，让孩子在真实项目中学习、创造与交付。
```

5. 可访问性：

   * 按钮语义正确
   * 标题层级合理
   * 图片或图标有 aria-hidden 或合适说明
   * 不要只靠颜色传达信息

6. 性能：

   * 不引入大型动画库
   * 不使用大背景图
   * SVG / CSS 优先
   * 首屏加载要轻

## 验收标准

完成后请确认：

* 可以通过 `/ai-builder-lab` 访问页面
* 页面不是整张图片，而是真实 HTML/CSS
* PC 端是大网页连续滚动
* 手机端是 H5 长页滚动
* 首屏突出“能力三角”
* “能力三角”比“AI工具课”更突出
* 顶部有“中国教育方向”这一段
* 文案包含“我们关注的，不只是会不会用工具”
* 审美力文案突出“AI工具平权后的稀缺竞争力”
* 页面整体浅色、大气、有留白
* 不使用 fullpage.js
* 不破坏现有网站
* 运行 lint/build，修复明显错误

## 重要设计判断

请优先保证：

```text
高级感 > 炫酷感
清晰表达 > 动效复杂
能力三角 > 课程列表
中国家长逻辑 > 国际案例堆砌
长期品牌资产 > 一次性活动页
```

请先实现一个稳定、可维护、视觉接近参考图的第一版。不要过度工程化。
