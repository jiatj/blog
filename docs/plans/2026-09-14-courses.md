# 课程模块 Implementation Plan

**Goal:** 在现有 portal 增加少量多课程阅读能力，并提供手工上传后的校验、发布和回退命令。

**Architecture:** 保留现有 Next.js 与主题；课程使用独立 JSON 目录和标准 Markdown。CLI 校验并生成不可变发布目录，原子切换当前版本；动态课程页面和资源路由直接读取版本，无后台、数据库或 webhook 扩展。

**Tech Stack:** Next.js 16、React 19、TypeScript、Node.js 24；沿用 unified/remark 解析体系，补齐 GFM 与 HTML 输出。

## 设计边界

- `/zh/courses` → `/zh/courses/[course]` → `/zh/courses/[course]/[lesson]`；英文入口跳转中文，标注中文内容。
- 教材式排版：暖灰纸面、细分隔线、章节编号、两栏阅读、手机折叠目录；遵循现有明暗主题。
- 配置管理标题、顺序和状态，Markdown 不重复配置。guide/lesson 进入顺序，reference 独立查阅。
- 仅标准 Markdown，不执行 MDX/HTML；教师备注、幻灯片配置必须整理后发布。缺文件、断链、无效锚点和越界路径阻止发布。
- 服务器必须有持久化可写磁盘；单机文件发布，多实例部署不在本版范围。
- 不改动既有博客/项目导入行为；不提交或覆盖原有未提交工作。

## 实施顺序与验收

1. 新增 `lib/courses/{types,markdown,package,store}.ts` 和 `scripts/course.mjs`：目录验证、标准 Markdown 渲染、资源映射、版本发布与回退。
2. 新增 `scripts/test-courses.mjs`：真实临时目录验证重复标识、草稿隔离、断链/锚点、中文资源、并发锁、失败保留旧版本、回退。
3. 新增课程三层路由、资源路由及 `components/courses/`：用示例课程验证目录、顺序导航、相关知识点、代码复制和移动布局。
4. 小范围修改导航、语言切换、站点地图、package scripts；新增 `doc/courses.md` 并更新内容模型、README。
5. 执行 `npm run test:courses`、`npx tsc --noEmit`、`npm run build`；本机生产模式验证发布后无需重启即可读取页面及附件，并进行浏览器明暗主题与窄屏检查。
