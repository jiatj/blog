# tiejunjia.com SEO 调整

## 范围与决定

按用户提供的 SEO 建议完善现有 Next.js 能力，保留简洁页面、品牌主标题和 Markdown 发布方式，不引入 SEO 后台或新依赖。

- 主域名：`https://www.tiejunjia.com`。非 www Host 永久跳转（308），保留路径与查询参数；代理/CDN 必须透传 Host 或配置同等跳转。
- 每页独立 title / description / canonical；默认 OG 类型为 website，文章、讲义和造物日志为 article。中文与英文使用对应搜索文案。
- hreflang 仅关联实际发布的同 slug / ID 内容。课程只提供中文；教育页面正文目前只有中文，英文路由 canonical 指向中文，不进入 sitemap。
- sitemap 每次读取当前公开内容；不纳入草稿、英文课程跳转地址；不以请求时间伪造 lastmod，无有效日期时省略。
- 按真实字段输出 WebSite、ProfilePage/Person、BlogPosting、Course、SoftwareApplication，JSON-LD 转义 `<`。不虚构资历、价格、评分或账号链接。
- 文章作者链接到关于页；共同标签推荐最多三篇文章，提供文章、项目和课程入口。关于页占位社交链接改为已有二维码图片，保留扫码方式。
- 优先使用文章/项目/课程封面；没有封面时使用 1200×630 的 `/og` 品牌分享图。

## 上线人工验收与限制

- 手机与桌面检查首页新简介、文章末尾链接、关于页二维码和课程封面。
- 线上抓取本次未成功；不据此判定线上 robots / sitemap 缺失。未部署、未验证实际收录和 Core Web Vitals，不承诺排名或富媒体结果。
